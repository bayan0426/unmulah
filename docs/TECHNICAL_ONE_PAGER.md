# UNMULAH technical one-pager

## Problem

Deaf users and sign-language users need respectful, accessible ways to engage
with Quran learning. Existing generic hand-recognition workflows do not provide
Quran-safe references, local privacy, or transparent limitations.

## Current MVP

UNMULAH supports an Al-Ikhlas fingerspelling-recitation MVP. A user explicitly
starts the camera, signs letters, releases after each accepted letter, and sees a
deterministic comparison with the selected trusted reference.

## Why this AI approach

MediaPipe extracts 21 hand landmarks; a local MLP evaluates a 43-class softmax
vector. The app limits candidate classes to the selected reference vocabulary
without renormalizing probabilities, then requires temporal agreement and hand
release before accepting a letter.

## Privacy and safety

Frames and inference stay in the browser. No face recognition, video recording,
or upload is used. Quran text and Tafsir are not generated by AI. Comparison is
deterministic, not a language model judgment.

## Limits and next step

This is assistive feedback, not a final assessment of memorization. It needs
specialist and Deaf-user validation. Next priority is a reviewed official Quran
data package and legally reusable, expert-validated sign assets.
